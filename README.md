# Sales Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from raw data preparation to business insights and dashboard presentation.

The workflow combines **Python, SQL, and Power BI** to transform sales data into actionable insights. A final presentation is also prepared to communicate the key findings in a clear, business-friendly format.

### Project Goals

- Clean and prepare raw sales data.
- Perform exploratory data analysis (EDA).
- Analyze sales performance using SQL.
- Build an interactive Power BI dashboard.
- Identify important product and regional trends.
- Present the findings in a recruiter-friendly report and presentation.

---

## Dataset

The dataset contains sales transaction records with the following fields:

| Column | Description |
|---|---|
| `Order ID` | Unique identifier for each order |
| `Order Date` | Date of the order |
| `Customer ID` | Unique customer identifier |
| `Product` | Product purchased |
| `Category` | Product category |
| `Region` | Customer/order region |
| `Quantity` | Number of units sold |
| `Unit Price` | Price per unit |
| `Payment Method` | Payment method used |
| `Revenue` | Revenue generated by the transaction |

## Project Steps

### 1. Load the Data

The raw dataset was imported into Python using Pandas.

The initial inspection focused on:

- Dataset structure and dimensions
- Data types
- Missing values
- Duplicate records
- Numerical distributions
- Potential data-quality issues

### 2. Exploratory Data Analysis

EDA was performed to understand the main characteristics of the dataset and identify patterns worth investigating.

Key areas included:

- Revenue distribution
- Product performance
- Sales quantity
- Regional performance
- Unit prices
- Missing and unusual values

### 3. Data Cleaning

The data was cleaned and prepared for analysis.

Main cleaning tasks included:

- Converting `Order Date` to a proper date format
- Handling missing values in `Region`, `Quantity`, and `Payment Method`
- Converting `Quantity` to an integer data type
- Checking numerical values for inconsistencies
- Verifying the final dataset before analysis

The cleaned dataset was then used for SQL analysis and Power BI reporting.

### 4. SQL Analysis

SQL was used to answer business questions and validate analytical findings.

Examples of questions addressed include:

- What is the total revenue?
- Which products generate the most revenue?
- Which products have the highest sales quantity?
- Which region generates the most revenue?
- What is the average unit price by product?
- Which products or regions require further investigation?

The SQL layer demonstrates the ability to translate business questions into practical queries using aggregations, grouping, filtering, sorting, and other analytical techniques.

### 5. Power BI Dashboard

The cleaned data was imported into Power BI to create an interactive dashboard.

The dashboard includes KPIs and visualizations covering:

- Total Revenue
- Average Revenue
- Revenue by Product
- Revenue by Region
- Quantity Sold by Product
- Average Unit Price by Product
- Top-performing products
- Regional performance

The dashboard is designed to help a business user quickly understand sales performance and identify areas requiring attention.

### 6. Report & Presentation

The analytical results were documented in a concise report and converted into a presentation using Gamma.

The presentation focuses on:

1. Business context
2. Data and methodology
3. Key findings
4. Important trends
5. Business insights
6. Recommended actions

## Results & Key Insights

The analysis produced several notable findings:

- **Cairo** was the highest-revenue region.
- **Mouse** generated the highest revenue among the products analyzed.
- **Keyboard** had the lowest revenue among the products analyzed.
- **Laptop** had the highest total quantity sold.
- **Headset** had the highest average unit price.
- Total revenue was approximately **3.1 million** in the analyzed dataset.

These results demonstrate how the same dataset can be viewed from multiple business perspectives: revenue, volume, pricing, product performance, and geography.

> Note: The exact figures may change if the dataset is updated or additional transformations are applied.

---

## Business Recommendations

Based on the findings, potential business actions include:

- Investigate why Cairo generates significantly more revenue than other regions.
- Analyze the strong revenue performance of the Mouse and identify opportunities to increase its sales further.
- Review the low performance of the Keyboard and determine whether pricing, demand, or product positioning is affecting sales.
- Investigate the high sales volume of Laptops and whether related products can be promoted alongside them.
- Evaluate the pricing strategy of products with higher average unit prices, particularly Headsets.

The recommendations are intended as starting points for further business investigation rather than conclusions based on sales data alone.
